# Playbook: Sincronización docs-código

## Cuándo usar
Cuando cambian fórmulas, reglas de validación, estructura de pantallas o arquitectura.

## Flujo
1. Identificar comportamiento cambiado
2. Ubicar documento fuente afectado
3. Actualizar descripción y ejemplos
4. Verificar que no hay contradicciones cruzadas

## Entrega
- Lista de documentos tocados
- Qué sección se actualizó
- Motivo del cambio
