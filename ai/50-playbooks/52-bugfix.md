# Playbook: Corrección de bug

## Entrada requerida
1. Síntoma observable
2. Pasos de reproducción
3. Resultado actual vs esperado
4. Datos de ejemplo mínimos

## Flujo de ejecución
1. Reproducir bug
2. Aislar causa raíz
3. Corregir sin regresiones
4. Añadir o ajustar prueba
5. Verificar escenario base y borde
6. Documentar lección aprendida si aplica

## Salida esperada
- Causa raíz concreta
- Fix aplicado
- Evidencia de no regresión
