# Playbook: Nueva funcionalidad

## Entrada requerida
1. Objetivo funcional
2. Alcance exacto (incluye/excluye)
3. Criterios de aceptación
4. Restricciones técnicas
5. Pruebas esperadas

## Flujo de ejecución
1. Leer contrato y precedencia
2. Identificar archivos objetivo
3. Implementar por capas (modelo, servicio, UI)
4. Verificar
5. Actualizar documentación afectada
6. Entregar resumen final

## Salida esperada
- Lista de archivos cambiados
- Qué comportamiento nuevo se añadió
- Evidencia de validación
- Riesgos pendientes
